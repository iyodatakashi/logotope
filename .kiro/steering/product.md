# Product Overview

logotope は、特定のテーマに対してAIが多様な立場のペルソナを生成し、マルチエージェント構造でAI同士が討論を行い、その内容をウェブコンテンツとして公開するプラットフォームである。

## Core Capabilities

- **ステークホルダー調査**: テーマに関係する多様な立場をAIが網羅的に分析・マップ化する
- **ペルソナ自動生成**: 調査結果に基づき、具体的な人物像（属性・信念・取材レコード）をAIが生成する
- **マルチエージェント討論**: 各ペルソナとファシリテーターが独立したAIエージェントとして相互に会話し、討論コンテンツを生成する
- **気づきの追跡**: 討論を通じて各ペルソナに生じた気づき（他者の視点の受容や新たな認識）を記録・可視化する
- **ウェブ公開**: 生成された討論を読みやすいウェブコンテンツとして公開する

## Target Use Cases

- 管理者がテーマを設定し、AIが討論コンテンツを自動生成する
- 閲覧者が複数の立場の意見を公平に閲覧し、多様な視点を理解する
- 社会的マイノリティを含む声が届きにくい立場の意見を可視化する

## Value Proposition

SNSでは声の大きい一部の人の言論が支配的になり、マイノリティの意見が埋もれている。logotope はAIを使ってあらゆる立場を代弁させることで、SNSに代わる新しい言論可視化の仕組みを提供する。討論に結論を求めず、意見の多様性そのものを価値として提示する点が独自の特徴である。
