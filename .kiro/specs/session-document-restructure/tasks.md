# Implementation Plan

## 1. 型定義の更新（Foundation）

- [x] 1.1 (P) バックエンドの討論・チャプター型を新構造に更新する
  - チャプタードキュメントを表す型（章メタ・ターン配列・論点状態・進行ステータス）を追加する
  - ターン型から所属チャプターを示すフィールドを除去する（チャプタードキュメント自体が所属を示す）
  - セッション型からチャプター・進行インデックス・メタデータ参照を整理する
  - 完了状態: 新しいチャプター型がビルドを通り、ターン型から chapterId が消えている
  - _Requirements: 2.5, 4.4_
  - _Boundary: functions types/debate.types.ts_

- [x] 1.2 (P) フロントエンドの型を新構造に更新する
  - チャプタードキュメント・章分析・討論後コメント専用ドキュメントの型を追加する
  - セッション型を除去し、章定義型から開始ターンインデックスを除去する
  - 完了状態: セッション型への参照が型定義から消え、新ドキュメント型が利用可能になる
  - _Requirements: 1.6, 2.5, 4.4_
  - _Boundary: src lib/models/session/session.types.ts_

## 2. バックエンド: Phase4 チャプター生成の書き込み先変更

- [x] 2.1 チャプター生成をチャプターコレクションと章分析ドキュメントへの書き込みに変更する
  - 各チャプターを独立したドキュメント（章メタ・空のターン配列・進行ステータス pending・順序インデックス）として書き込む
  - チャプター生成の中間成果物（切り口）を専用の章分析ドキュメントに書き込む
  - セッションドキュメントの作成・初期化を廃止する
  - 完了状態: Phase4 実行後、チャプターコレクションと章分析ドキュメントが生成され、セッションドキュメントは作成されない
  - _Requirements: 1.1, 1.3, 1.6_
  - _Depends: 1.1_

## 3. バックエンド: Phase5 討論実行の書き込み先変更

- [x] 3.1 ターンの書き込み・読み込みをチャプタードキュメント基準に変更する
  - ターン追記先を対応するチャプタードキュメントのターン配列に変更する（原子的追記を維持）
  - 全ターン取得をチャプターコレクション全件読み込み＋ターンインデックス順の結合に変更する
  - 完了状態: 新規ターンが該当チャプタードキュメントに追記され、全ターン取得が章をまたいで正しい順序で返る
  - _Requirements: 2.1, 2.2_
  - _Depends: 1.1_

- [x] 3.2 討論オーケストレーションの章参照と進行状態をチャプタードキュメントに移す
  - 章の読み込み元をチャプターコレクション（順序インデックス順）に変更する
  - 進行インデックスの更新を廃止し、章開始時に進行ステータス running、章終了時に completed をチャプタードキュメントに書く
  - 冪等性チェックを進行ステータス completed 判定に置き換える
  - 論点状態の更新先を対応するチャプタードキュメントに変更する
  - 完了状態: 討論実行中、実行中チャプターのステータスと論点状態がチャプタードキュメントに反映される
  - _Requirements: 1.4, 3.1, 3.2, 3.4_
  - _Depends: 3.1_

- [x] 3.3 討論完了処理を専用ドキュメント書き込みに変更する
  - 討論後コメントの書き込み先を専用の討論後コメントドキュメントに変更する
  - 完了時のメタデータ書き込み（総ターン数・完了時刻）を廃止する
  - トピックの進行ステータスを生成済みに更新する処理は維持する
  - 完了状態: 討論完了後、討論後コメントが専用ドキュメントに保存され、セッションメタデータは書かれない
  - _Requirements: 1.5, 1.8_
  - _Depends: 3.1_

## 4. バックエンド: リセット・再開・engagements 移動

- [x] 4.1 engagements の格納先をトピック直下に移動する
  - 発言意欲履歴・保留インテントの読み書き先をトピック直下の engagements コレクションに変更する
  - 章開始時の保留インテント一括ロードを新パスから行う
  - 完了状態: 討論中の engagements がトピック直下に蓄積され、セッション配下のサブコレクションを使わない
  - _Requirements: 1.1_
  - _Boundary: functions pipeline/debate/engagement.ts, queued-intents.ts_

- [x] 4.2 チャプターやり直し処理をドキュメント操作に置き換える
  - 対象チャプター以降のチャプタードキュメントのターンをクリアし、論点状態を削除し、進行ステータスを pending に戻す
  - 討論後コメントドキュメントを空にし、トピックの進行ステータスを実行中に戻す
  - engagements の対象ターン以降の履歴を削除する
  - 配列フィルタリングによるターン削除ロジックを廃止する
  - 完了状態: 特定チャプターのやり直し後、対象以降のチャプターのみがリセットされ、それ以前のチャプターは保持される
  - _Requirements: 2.3, 3.3, 4.2_
  - _Depends: 3.1, 4.1_

- [x] 4.3 討論再開の実行中チャプター特定をチャプターコレクションから行う
  - セッションからの章参照を廃止し、チャプターコレクションから対象チャプターを特定して再開タスクを投入する
  - 完了状態: 停止した討論の再開が、チャプターコレクションを参照して正しいチャプターから再開する
  - _Requirements: 1.2_
  - _Depends: 3.2_
