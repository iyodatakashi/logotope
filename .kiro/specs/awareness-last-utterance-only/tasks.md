# Implementation Plan

- [x] 1. 気づき検出の発生源を直前発言のみに限定する
- [x] 1.1 傾聴の気づき検出入力・出力・指示を直前発言限定に変更
  - 傾聴評価の会話提示に発言単位の識別子を付与する（発話生成と共有する会話整形は変更せず、傾聴側の提示にのみ付ける。実 turnId ではなくウィンドウ内ローカル序数を提示し、序数→発言の対応をコードで解決する方針を優先）
  - 気づき検出指示を「発生源は提示会話の最後の1発言（直前の発言）のみ。それ以前は直前発言を理解する文脈で、発生源にしない」に改訂し、reception のとき反応した発言の識別子を出力させる
  - 気づきの LLM 出力から話者IDの申告を廃し、反応した発言の識別子を出力する形に差し替える
  - score/mode の指示文・スコア基準・直近ターンの参照範囲・既存の気づき抑制文（単なる同意・言い換え・既出の繰り返しを記録しない／該当なしは記録しない）を字義的に据え置く
  - 完了状態: 傾聴評価で直前発言に識別子が付与され、検出指示が直前発言のみを発生源とし、気づき出力に反応発言の識別子が含まれる（score/mode の指示・基準は差分なし）
  - _Requirements: 1.1, 1.3, 2.3, 4.1, 4.2, 4.3_
  - _Boundary: evaluateEngagement_

- [x] 1.2 後処理で発言ID突合・リスナーガード・帰属導出・drop を実装
  - 直前発言の話者が評価対象ペルソナ自身のとき、気づきを無し（null）にするガードを追加する
  - reception は、反応した発言の識別子を直前発言と突合し、一致するときのみ採用する。不一致（直前より前の発言・同一話者の過去発言を含む）は気づきを drop（null）する
  - 採用した reception の話者を直前発言から導出して帰属させる（直前がファシリテーターのとき話者は無し＝null）。self は話者を持たない（null）まま維持する
  - 追加の LLM 評価は設けず、既存の score/mode 相乗り評価1回のまま行う
  - 完了状態: 直前発言に一致した reception のみが直前話者へ帰属して残り、過去発言由来・話者自身由来の気づきは残らない
  - _Requirements: 1.1, 1.2, 2.1, 2.2, 3.1, 3.2_
  - _Boundary: evaluateEngagement_

- [x] 2. 発生源限定・帰属・非干渉を検証する
- [x] 2.1 気づき検出の単体テストを追加
  - 反応発言が直前発言に一致する reception が採用され、直前話者へ帰属することを検証する
  - 反応発言が直前より前（同一話者が直前と過去の両方に登場するケースを含む）を指す reception が drop されることを検証する
  - 直前発言が評価対象ペルソナ自身のとき気づきが無しになること、直前がファシリテーターのとき採用時の帰属が無し（null）になること、self の帰属が無しのまま維持されることを検証する
  - 同一の LLM 出力に対し score/mode/意欲サマリの解決が本変更前後で変わらないことを検証する
  - 完了状態: 上記ケースを網羅する単体テストが追加され、緑になる
  - _Requirements: 1.1, 1.2, 2.1, 3.1, 3.2, 4.1_
  - _Depends: 1.2_

- [x] 2.2 傾聴経路の結合テストを維持・追加
  - 傾聴→永続→発言消費の同ターン反映が維持されること（永続・消費経路が無改変）を回帰確認する
  - 一括評価経由で直前話者が対象外のまま、リスナーの気づきのみが永続されることを検証する
  - 完了状態: 既存の同ターン反映結合テストが緑のまま維持され、リスナー限定の永続が確認できる
  - _Requirements: 2.2_
  - _Depends: 1.2_
