# Implementation Plan

> 討論チェーンの章末から「章まとめ発言」と「クロージング発言」の生成のみを取り除く。章の完了確定・次段起動（次章 open / comments）・討論終端（generated）は不変に保つ。生ディベートの既存データと編集フェーズの読み物クロージング（別系統）は変更しない。

- [x] 1. 章末の発言生成を止め、章の完了処理に集約する
  - 章末処理（章まとめ側・クロージング側）から発言生成の呼び出しを取り除き、章の完了確定と論点状態クリーンアップのみを行う単一の章完了処理に集約する
  - 討論オーケストレーションの章末分岐は、章完了処理を呼んだうえで次段（非最終章＝次章の開始／最終章＝事後コメント）の起動を従来どおり維持する（進行構造・世代ゲート・冪等再入は不変）
  - 章末を通る既存テスト（章遷移・冪等性・介入ゲート・インライン・ファクトチェックのフロー等）の期待を、章まとめ・クロージング発言が追記されないことと、章遷移・事後コメント到達・討論完了（generated）が従来どおり成立することを検証する形に更新する
  - 完了条件: 討論を通しで走らせると章まとめ・クロージング発言が生成・追記されず、章から次章へ進み、最終章の後に事後コメントを経て討論が generated に到達する
  - _Requirements: 1.1, 1.2, 1.3, 2.1, 2.2, 2.3, 3.1, 3.2, 3.3, 3.4, 3.5_
  - _Boundary: 討論オーケストレーション, 章末ステップ_

- [x] 2. 未使用化した章まとめ・クロージング生成ロジックを削除する
  - 未使用となった章まとめ・クロージングのターン生成ロジックと、討論側の章まとめ・クロージング生成エージェント、およびそれら専用のスキーマを削除する
  - 他のエージェントが共有する中立プロンプト生成など、削除対象以外の共有ロジックは保持する（討論側クロージングと編集側クロージングは別物として取り違えない）
  - 削除に伴い未使用化したインポート（初期信念・気づき整形など）を取り除き、他所で使用が残るものは保持する
  - 削除対象の生成関数を参照していたテストのモック・ケースを取り除く
  - 完了条件: 章まとめ・クロージングの生成関数と専用スキーマがコードベースから消え、型チェックとリンタがデッドコード・未使用インポートなしで通る
  - _Requirements: 6.1, 6.2_
  - _Boundary: 討論ターン生成, ファシリテーターエージェント_

- [x] 3. 回帰と非干渉を確認する
  - 事後コメント生成・編集後章・信念変化追跡・ファクトチェック・engagement 判定が従来どおり動作し、会話ターン・口火・章導入発言が引き続き生成されることを確認する
  - 編集フェーズの読み物イントロ・クロージング（別系統）の生成・保存・表示が不変であることを、当該テスト群が無変更で緑のまま通ることで確認する
  - 既存の生成済み討論データ（過去の章まとめ・クロージング発言を含む）が改変されないことを確認する
  - ビルド・型チェック・リンタ、およびユニット/インテグレーションの全テストが緑であることを確認する
  - 完了条件: 全テストスイートが緑で、編集クロージングおよび下流各処理のテストが変更なく通る
  - _Requirements: 4.1, 4.2, 4.3, 5.1, 5.2, 6.2_
