# 受け入れチェックリスト（スタイル基準＋軸適合）

> 目的: 生成物の合否を主観でなく共通基準で機械的に判定する。
> 使い方: 各項目を Yes/No で判定する。**A（スタイル基準）は全項目 Yes が合格の必須条件**。1つでも No なら不合格とし、逸脱項目を記録して指示改善へ回す。**B（軸適合）は指定した VariationSpec と一致すること**。合格物のみ後処理（資産化）へ進む。

## A. スタイル基準（全項目 Yes が必須・Req 1, 4）

| # | 判定項目 | 合格（Yes）の条件 |
|---|---|---|
| A1 | 背景の一様性 | 背景が無地の白一色。グラデーション・小物・影・枠・テクスチャが無い |
| A2 | 被写体の暗さ（マスク抽出可能性） | 髪・衣服・輪郭が十分に暗い黒基調で、輝度→アルファ変換で被写体を抽出できる |
| A3 | 顔の非描写 | 目・鼻・口・眉が描かれていない。顔の内側は白のネガティブスペース |
| A4 | 構図＝バストアップ | 胸から上の構図で、正方1:1に収まる。全身・顔アップ・見切れ過多でない |
| A5 | 2色分離可能なネガティブスペース | 「被写体（髪・衣服・輪郭）」と「非被写体（顔の内側・被写体外の背景）」が明確に分かれ、2色に塗り分け可能 |
| A6 | 線／塗りの様式 | 黒のシルエット塗り主体で、写実的な陰影・カラー・写真調でない |

## B. 軸適合（指定 VariationSpec と一致・Req 2, 3）

| # | 判定項目 | 合格（Yes）の条件 |
|---|---|---|
| B1 | 年齢帯 | 指定した年齢帯に見える |
| B2 | 性別 | 指定した性別に見える |
| B3 | 髪型 | 指定した髪型カタログの値に一致する |
| B4 | アングル | 指定（正面／斜め約30度）に一致する |
| B5 | メガネ | 指定（あり／なし）に一致する |
| B6 | 表情 | 話している最中の真剣な様子（笑顔でない） |

## 合格例／不合格例（判断が割れる項目の補足・Req 1.4）

### A1 背景の一様性
- 合格: 完全な白背景に被写体のみ。
- 不合格: 背景に薄いグレーのグラデーション、床の影、装飾枠が入っている。

### A3 顔の非描写
- 合格: 顔の内側が白く、目鼻口が一切無い（既存サンプル `30_female_20.png` 相当）。
- 不合格: 目や口がうっすら描かれている／顔に陰影がついて表情が読める。

### A5 2色分離可能なネガティブスペース
- 合格: 顔の内側と背景がひと続きの「非被写体（白）」として被写体から切り離せる。
- 不合格: 顔の内側が髪と同じ黒で塗りつぶされ、背景色で抜くと顔まで背景色になる（顔と背景を独立に扱えない）。

### A2 被写体の暗さ
- 合格: 髪・衣服がほぼ黒（低輝度）で、白背景と十分なコントラストがある。
- 不合格: 髪がグレーで背景との差が小さく、輝度→アルファで半透明にしか抜けない。

### B3 髪型
- 合格: 指定「ショートボブ」に対し、肩上で切り揃えたボブになっている。
- 不合格: 指定「ショートボブ」に対し、ロングヘアが生成されている（AI 裁量で逸脱）。
