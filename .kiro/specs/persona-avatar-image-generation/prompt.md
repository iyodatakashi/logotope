# 規範プロンプト（スタイル固定文＋軸プレースホルダ）

> 目的: スタイルを固定したうえで、各軸の値を明示的に指定してバリエーションを出し分ける。
> 実行時の組み立ては [prompt-builder.ts](../../../scripts/avatar-generation/prompt-builder.ts)（`buildPrompt(spec)`）が本テンプレートと同一趣旨で決定的に生成する。本ファイルは人間可読の正本。

## スタイル（固定・常に含める）

- 背景は無地の白一色にする（グラデーション・小物・影・枠を置かない）
- 顔は描かない（目・鼻・口・眉を描かず、輪郭の内側は白のネガティブスペースにする）
- 黒基調のシルエット調にする（髪・衣服・輪郭を黒で塗り、中間調は最小限にする）
- 構図はバストアップにする（胸から上、正方1:1の枠に収める）
- 髪と衣服は単純化した形にする（過度なディテール・テクスチャ・柄を避ける）
- 表情は話している最中の真剣な様子にする（笑顔にしない）

## バリエーション（指定値で出し分ける・AI の裁量任せにしない）

| 軸 | プレースホルダ | 取りうる値 |
|---|---|---|
| 年齢帯 | `{ageBand}` | 10歳（子供） / 10〜20代 / 30〜40代 / 50〜60代 / 70代以上 |
| 性別 | `{gender}` | 女性 / 男性 |
| 髪型 | `{hairStyle}` | 対象バケットの[髪型カタログ](../../../scripts/avatar-generation/variation-spec.ts)から選ぶ |
| アングル | `{angle}` | 正面 / 斜め約30度 |
| 服装 | `{outfit}` | 年齢帯に応じた服装 |
| メガネ | `{glasses}` | あり / なし |

- ポーズ／表情は「話している最中の真剣な様子（笑顔でない）」で固定するため、可変軸として指定しない。

## 参照画像（スタイルアンカー・最大3枚）

- 既存サンプル（`src/lib/assets/images/NN_female_XX.png`）を最大3枚添付し、様式（構図・黒基調・単純化）に寄せる。
- 参照は**様式のアンカー**であり、人物の同一性（顔立ち・特定個人）は模倣させない。
