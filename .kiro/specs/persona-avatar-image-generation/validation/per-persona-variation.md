# per-persona バリエーション生成 フィジビリ結論

> 提供サンプル（黒ベタ・顔なし・白抜き featureless のシルエット）をベースに、ペルソナごとに固有アバターを同テイストで生成できるか。2026-07-20 実施。

## 結論: 成立（per-persona 生成は可能）

提供サンプル1枚を編集ベースにすれば、**同テイストのまま髪型・体型・ポーズ・年齢を振った別個体**を、1体ずつの単発生成で作れる。スケール一貫も生成側で担保できる。

## 検証で確定した要点

### 1. テイストは「画像」に宿る（ツールの記憶に依らない）
- 元サンプルは ChatGPT で text-only 生成されたが、Gemini でも**元サンプルをベースに添付して編集**すれば黒ベタ・顔なしのテイストがピクセルから移る。ChatGPT が過去を忘れていても問題にならない。
- 参照画像を「別 demographic のスタイルヒント」として足す当初案は誤り（男性生成で線画＋顔に逸脱）。**編集ベース方式が正解**。

### 2. 振れる軸（すべてシルエットで表現）
- **髪型**: ベリーショート/ウルフ/ツーブロック/マッシュ/パーマ 等で別人になる。
- **体型**: 細身/肥満（二重顎・太い首・恰幅）/筋肉質（広い肩幅）が明確に出る。
- **ポーズ**: 腕組み/顎に手/斜め/手を下ろす/横向き。
- **年齢**: 灰色や皺に頼らず、**頭身（頭:体 比率）・生え際・姿勢・髪型のシルエット**で表す（子供＝大きい頭身、高齢＝生え際/白髪は筋のストロークで表現）。

### 3. スケール一貫は「後処理検出」でなく「生成側固定」で担保する
- **後処理の幾何検出は髪型・ポーズに対して頑健にならない**（顔穴＝首連結で破綻、首くびれ＝ロングヘアで破綻）。シルエットは髪が支配的で、鍵となる特徴を髪が隠すため。→ 自動正規化は不採用。
- 正解: 生成プロンプトで**「ズーム（頭の大きさ）と目線の高さだけを基準画像と完全一致させる」**と固定し、体型・髪型・ポーズは自由に変える。独立した単発生成（＝per-persona）でも頭サイズ・位置が揃う。「まとめて1枚に描く」はスケールは揃うが per-persona に不適（ペルソナは1体ずつ増える）。
- 構図を固定しすぎると体型変化まで消えるので、**固定はズーム＋目線のみ**に切り分ける。

### 4. 後処理・様式の扱い
- 生成時に **「純白背景・影/ドロップシャドウなし」** を明示（影は後処理で半透明ハローになるため）。
- 輝度→アルファ変換で、白い服・グレーの髪は**階調（薄い色）**として自然に出る（崩れない）。高齢の白髪は「髪をベタ塗りにせず筋のストロークで描く」と白髪感が出る。
- フレーム占有は**高さ基準で正規化・横ははみ出させる**（大柄でも全体を縮小しない）。ただしスケール一貫の本命は上記3の生成側固定。

## 使用パイプライン（本リポジトリ）
- 生成: [gemini-image-client.ts](../../../scripts/avatar-generation/gemini-image-client.ts)（`gemini-2.5-flash-image` + `responseModalities:['TEXT','IMAGE']` + ベース画像添付）。実行は [functions/src/avatar-gen.eval.test.ts](../../../functions/src/avatar-gen.eval.test.ts)（eval・鍵はシークレット注入）。
- 後処理: [postprocess.py](../../../scripts/avatar-generation/postprocess.py)（輝度→アルファ・影しきい値・高さ基準正規化・256px）。
- 4コマシート分割: 白ガター検出で 2×2 → 4分割（提供サンプルは1枚に4体）。

## 次フェーズ（別 spec に切り出し）
- 本番実装は **ペルソナ作成時にオフラインで1回生成し、そのペルソナの資産として保存**（ランタイム毎回生成はしない）。
- 生成失敗（画像を返さない/崩れ）に備え**リトライ＋受け入れチェック**でゲート。
- (年齢帯×性別)の**基準ベース**を確定（提供サンプルから1体ずつ切り出して使える）。
