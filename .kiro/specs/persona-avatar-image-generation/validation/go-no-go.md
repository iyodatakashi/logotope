# 量産可否（Go / No-Go）結論（Task 4.4）

## 結論: 条件付き Go

各(年齢帯×性別)バケットに **on-style の参照アンカーを1枚確定する**ことを前提に、量産へ進んでよい。スタイル再現性・後処理・2色独立着色はいずれも成立を実証済み。

## 観点別の判断

| 観点 | 判断 | 根拠 |
|---|---|---|
| スタイル再現性 | 高（条件付き） | アンカー一致の女性で 3/3（100%）。不一致の男性で 0/1。→ 再現性はアンカー依存 |
| 網羅可能性 | 可 | 軸（年齢帯・性別・髪型・アングル・メガネ・服装）は指示で出し分け可能。ただし各 demographic に on-style アンカーが要る |
| 受け入れ品質 | 可 | チェックリストで機械的に合否判定できた。合格物は決定的後処理でアセット化可能 |
| 独立着色の成立 | 成立 | 実生成→後処理アセットを 2色（silhouette/background）で表示し、顔の内側が背景色で透け、縁が濁らないことを確認（4.3） |

## 未成立点と対策
- **男性（および女性以外の全 demographic）は現状の女性アンカーでは不成立**。
- 対策: 各バケットに on-style シード（黒ベタ・顔なし・バストアップ）を最低1枚確定し、それを以降のアンカーにする（鶏卵問題は「まず各バケット1枚を反復生成 or 手作業で確定」で解く）。あわせて [results.md](results.md) の指示改善案 1〜3 を適用。

## 量産に進む場合の残作業
1. **用意すべきパターン総数**: 髪型カタログ合計 **約80枚**（若年各10・70代以上各5、[variation-spec.ts](../../../scripts/avatar-generation/variation-spec.ts)）。副次軸（服装・メガネ・アングル）は各個体に割り当て、総当たりにしない。
2. **参照アンカー整備**: 各(年齢帯×性別)バケットの on-style シード画像を確定。
3. **`buildPrompt` 拡張**: demographic 別に参照セットを切り替え、テキスト規範に「全身黒ベタ／口・鼻・輪郭線なし」を追記。
4. **後処理**: 全合格候補に [postprocess.py](../../../scripts/avatar-generation/postprocess.py)（輝度→アルファ・正方1:1・256px、決定的）を適用。
5. **命名整備**: `{ageBandCode}_{gender}_{serial}.png`。`serial` は発番後不変。`SERIAL_REGISTRY` を量産分まで拡充。
